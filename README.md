# Econ Job Market 2026–27

A single-page view of every economics job listing on the [AEA JOE](https://www.aeaweb.org/joe/listings)
board for the 2026–27 cycle, rebuilt each morning.

**The page is at the Pages URL for this repository.** `index.html` is generated — edit the pipeline,
not the file.

What it does:

- every JOE listing for the cycle, sorted newest-posted first, with a NEW badge on the last week
- a fit score you set yourself: tick your JEL fields, the regions you would move to, and the kinds of
  position you want, and the table re-ranks for you. Nothing is ever hidden by a preference — it only
  sorts lower.
- star listings, track applications through Applying and Submitted, keep notes

**Your data stays in your browser.** Stars, applications, notes and preferences are written to your own
browser's local storage. They are never uploaded, never in this repository, and nobody else — including
whoever set this up — can see them. The flip side: clear your site data or switch machines and you start
fresh, so use **Back up or restore** at the bottom of the page to keep a copy.

Listings come from the AEA's public JOE feed. Deadlines and details can be wrong or stale; the listing
itself is the authority, and every row links to it.
